# 设计探索工作台 UI 原型

CUPPA 是一个面向设计探索的交互原型，包含项目桌面、画布、卡片与连线、搜索和外部 AI 摘录。仓库包含当前可运行的源码、素材、测试和[顶部搜索设计说明](docs/顶部搜索交互设计说明.md)。

## 本地运行

无需安装前端依赖或构建。在仓库根目录运行：

```sh
python3 -m http.server 8000 --directory dist
```

打开 [项目桌面](http://localhost:8000/)，点击 CUPPA 进入示例画布，也可以通过 [画布直达链接](http://localhost:8000/#cuppa) 打开。右侧加号可以创建独立项目。画布内容保存在当前浏览器；首次打开 CUPPA 时会加载示例卡片。

## 修改与协作

- 页面入口在 `dist/index.html`。JavaScript 和 CSS 也在 `dist/`，这个目录就是可直接编辑的源码。
- 有仓库写权限的协作者可以从 `main` 开分支、提交修改，再发 Pull Request。若仓库允许 Fork，也可以先 Fork 到自己的账号，再从 Fork 提交 Pull Request。
- 有 Node.js 时，在根目录运行 `node --test tests/ai-conversations.test.cjs` 验证 AI 摘录逻辑。
- Agent 检索是模拟流程。外部 AI 会在各平台打开，摘录可手动导入。卡片和草稿保存在浏览器本地，仓库包含的都是演示数据。
- 品牌图标和网页截图用作原型示例。AI 平台图标和设计素材的来源见 `dist/assets/` 下的来源记录。

## 资源卡片语义缩放

- 画布比例 < 65%：一级，仅标题、标签；预览图模糊作为背景。
- 画布比例 ≥ 65%：二级，预览、标签、标题、来源域名。点击来源在原位置展开三级窗口。
- 三级：窗口标题栏可拖动，右下角可调整大小；减号收回二级。缩小至一级保留窗口状态，放大后恢复。
- 华为官网在响应中设置 SAMEORIGIN 和 frame-ancestors，禁止本站直接嵌入。因此该示例使用明确标识的首屏快照，包含官网图片，可在画布内滚动。完整网页通过窗口右上角打开。其他网页使用 iframe；受来源站限制时可以外部打开。
- 现有卡片保留；首次更新自动添加一张华为示例，不重复添加。添加资源弹窗支持标题、链接、标签及可选预览图。


## 创建、连线与画布搜索

- 工具栏加号：创建卡片、创建区域、创建连线。创建卡片展开三种卡片类型。
- 创建区域后在空白处拖拽；区域标题可编辑，标题栏空白可拖动区域及创建时包含的卡片，右下角可调整大小，删除区域保留卡片。
- 靠近卡片边缘出现蓝色连接节点，拖至另一张卡片即可连接；也可使用创建连线后依次点选两张卡片。连线随卡片移动、缩放和窗口大小更新。选中连线后按 Delete 删除，Esc 取消创建。
- 左下角搜索为浅灰占位文字原位输入，回车打开中央深色缩略图面板。匹配标题、正文、标签和链接，支持类型筛选；点击结果定位到原卡片。仅展示当前画布真实内容。


## 直接框选

选择工具下从画布空白处拖拽会显示虚线矩形，触及的卡片实时高亮。松开后虚线框贴合所选卡片，右下角显示分别单独分析、寻找相似案例、自定义输入。空选区、点击空白或 Esc 取消；移动工具仍用于平移画布。操作基于所选卡片快照，分析为明确标注的任务演示，相似案例复用现有 Agent 搜索演示，自定义输入支持 Enter 提交与中文输入法。


## 想法卡片

想法卡改为无标题栏的块式便笺，文字、表格和涂鸦可混排，按内容自适应高度。底部保留创建者（头像、名称）及创建时间，拖动底部可移动卡片。旧卡片保留原文字与已有时间，不补造历史日期。新卡记录上海时区下的实际创建时间。

鼠标停留 650ms 后显示底部加号；点击加号添加一行文字，悬停加号 180ms 打开创建表格／涂鸦菜单；键盘聚焦加号后按向下箭头可打开菜单。默认表格 2 行 3 列，可编辑、增行、增列。涂鸦直接绘制，支持撤销、清空和删除。所有内容保存在当前浏览器；搜索、取用和选区任务读取最新的文字／表格内容。低于 65% 缩放时简化为文字摘要，放大后恢复表格与涂鸦。左侧默认想法记录可创建一张包含表格与涂鸦的示例卡片。


## 搜索方式与画布取用

Agent 模式持续显示蓝色光圈，输入提示可用自然语言说明目标、限制与偏好。两种模式的已选材料分别保存在各自草稿中；已有材料时回形针变蓝，移除全部材料后恢复。

个人模式点击回形针后，选择文字卡（或资源卡标题区域）提取可编辑关键词，不自动提交；选择图片卡或卡面图片进入图搜。涂鸦也可选作图片。公开图片链接跳转 Google Lens 图搜；本机图片保留在浏览器，提供保存与 Google Lens 上传入口，不伪装成已完成跨站上传。Agent 模式添加原卡片内容作为参考，不改写问题。


图片取用不再弹出独立预览面板，仅保留搜索框标签与回形针状态。提交时直接打开图搜入口；本机图片的保存操作放在来源菜单中。

## 外部 AI 对话与摘录资源

个人模式的来源面板包含搜索和外部 AI 对话，本机文件在搜索列表内。选择 ChatGPT、豆包或 DeepSeek 后，搜索框显示平台，提交会复制提问并打开对应官网；用户在官网自行粘贴、发送。复制失败时保留可手动复制的提问和网站链接。Agent 模式仍使用原有模拟检索，未连接这些产品的账号或聊天记录。

从资源卡片创建弹窗，或画布空白处粘贴可进入摘录导入。勾选段落后，一次保存生成一张资源卡片；可附带对应问题、原链接、对话名称、摘要及纯文字标签。「整段保存」保留本次粘贴的完整内容。Markdown 与富文本粘贴尽量保留列表、代码、表格；外部 HTML 转为安全的内容表示，不直接插入页面。未选中的段落不写入卡片，非连续片段会标识省略。

同一对话通过明确选取的对话或相同原链接关联，可以拥有多张摘录卡片。手动导入的左侧记录显示个人图标。一级为三行大字摘要与标签，二级为原文预览、可选问题和平台，三级为画布内本地阅读窗口，可查看同源摘录、再摘一段、派生想法卡片并连线；只展示已导入内容，不嵌入外部聊天站点。修改摘要与来源信息保留原文及摘取时间。

所有摘录与关联信息仍保存在当前浏览器。当前没有浏览器扩展、桌面快捷摘取、模型调用或账号历史同步。

逻辑测试：`node --test tests/ai-conversations.test.cjs`。
