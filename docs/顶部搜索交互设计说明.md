# 工作空间顶部搜索交互设计说明

版本 1.0　2026 年 11 月 4 日　用于界面设计与交互原型

顶部搜索支持两种工作方式：个人模式由用户在一个指定平台中查找；Agent 模式根据问题和参考材料，在指定来源或本机与全网范围内检索。两种模式共用入口，分别保存搜索草稿、来源选择与结果。本文覆盖组件布局、画布取用、平台面板、搜索流程、模式切换及异常状态。

## 核心设计决定

保留最前面的画布取用按钮，并根据模式改变用途与提示。个人模式将用户明确选取的文字加入可编辑的搜索词；Agent 模式添加原卡片或片段作为理解问题的参考。个人模式不自动分析整张卡，也不把卡片附件直接传给平台。

画布材料回答“基于什么找”，平台选择回答“去哪里找”。参考材料不等于搜索范围；例如一张论文卡可以帮助 Agent 在指定案例网站找设计案例，而不代表 Agent 必须搜索论文网站。

| 规则 | 个人模式 | Agent 模式 |
| --- | --- | --- |
| 平台数量 | 单选；点击平台即打开平台浮层 | 多选；点击只改变范围，提交后执行 |
| 未选平台 | 提示选择一个平台；不隐式选站点 | 显示“本机＋全网”，作为默认范围 |
| 画布取用 | 提取明确文字到输入框；用户可编辑 | 附加卡片、片段或区域作为参考 |
| 搜索执行 | 直接使用用户确认的搜索词 | 理解意图、组织检索、汇总带出处结果 |
| 结果位置 | 画布上方的平台浮层 | 搜索任务面板，可展开到侧栏 |

## 命名与边界

模式菜单保留“个人模式”“Agent 模式”，副说明分别为“自己在单个平台搜索”“让 Agent 跨来源查找”。此处仅控制搜索执行方式，与工作空间的自主探索或共创开关独立。搜索方式变化不改变画布上的 Agent 全局行为。


# 一 搜索框与展开面板

## 顶部组件顺序

从左至右：画布取用按钮 → 搜索输入区 → 执行按钮 → 模式选择。模式选择保持最右；输入为空时执行按钮不可用，模式切换始终可用。

个人模式示意：［取用画布］［输入关键词，在指定平台搜索…］［搜索］［个人模式 ▾］

Agent 模式示意：［添加参考］［描述你想找的内容…］［开始搜索］［Agent 模式 ▾］

| 元素 | 个人模式 | Agent 模式 |
| --- | --- | --- |
| 左侧按钮提示 | 从画布提取文字到搜索框 | 添加画布内容作为搜索参考 |
| 输入辅助 | 使用关键词；提交前可改写 | 可用自然语言说明目标、限制与偏好 |
| 参考状态 | 取用成功后文字进入输入框 | 输入框下显示可移除的参考标签 |
| 范围提示 | 在 某平台 搜索；未选时显示“请选择平台” | 指定来源名称；未选时显示“本机＋全网” |
| 执行按钮 | 搜索 | 开始搜索；执行时提供停止入口 |

## 聚焦后的面板结构

点击输入框后，下方展开面板。顶行显示“搜索范围”和单选或多选说明；中间显示常用平台；底部显示当前范围与执行入口。个人模式使用“选择一个平台”；Agent 模式使用“可多选；未选择时搜索本机与全网”。

常用平台显示名称、图标及可用状态，不只依靠图标识别。提供“管理来源”入口。来源清单取自已配置来源；支持哪些平台及能力需要后续验证，原型中不将未实现能力表现为可用。

Agent 模式将“本机”作为一个可选来源，与平台并列。未选择任何来源是默认的本机与全网；选择任意来源后，范围严格限定为所选项。清空来源立即恢复默认，并更新可见提示。

## 尺寸与收起

桌面初稿可将输入组件高度设为 44 像素，展开面板与搜索组件对齐；平台项热区至少 44 像素。常用来源过多时换行或折叠到“更多来源”，不压缩输入文字。空间不足时，参考标签与范围移到第二行，平台浮层可展开到侧栏。

点击画布空白处收起来源面板，草稿保留。Esc 先关闭最上层菜单或面板，再退出画布取用。完成收集、返回画布和关闭搜索面板都不清空未完成内容。


# 二 个人模式的搜索流程

## 直接使用关键词

首次进入显示常用平台，尚未选定平台。用户可以先输入关键词再点击平台，也可以先点击平台。平台单选；再次点击当前平台只恢复浮层，不取消选择。更换平台替换当前选择，不同时打开多个平台浮层。

输入了关键词时，点击平台立即在浮层中执行该关键词搜索。输入为空时，点击平台只打开该平台的搜索入口或首页，并聚焦可搜索位置；不产生空搜索请求。

选定平台后，用户在顶部修改关键词，按 Enter 或点击“搜索”才更新平台结果。未选平台时，按 Enter 展开来源面板并提示“先选择一个搜索平台”，保留输入。

## 平台浮层

浮层覆盖画布的局部区域，显示平台名称、此次提交的关键词、加载状态，以及收起、展开、在外部打开和关闭入口。浮层打开不改变画布的缩放和布局。

顶部输入区控制新一次搜索。用户进入平台原生页面后，其内部搜索、筛选和导航由该平台承担，不假设外部搜索框能持续双向同步。重新从顶部提交搜索时，以新的顶部搜索词发起一次导航。

平台内滚动操作页面，浮层外操作画布。只通过标题栏移动浮层；关闭后再次打开尽量恢复本次页面位置，无法恢复时回到最近提交的搜索。

## 从画布提取文字

点击取用按钮，来源面板收起，搜索草稿保留；画布进入明确的取用状态。用户点击卡片、框选对象或选择已有文本片段，底部出现取用操作条。Esc 或“取消”退出，不修改输入。

个人模式仅接受用户明确确认的文字。文字卡和文档卡可选择标题或正文片段；多选时在预览中列出各段，可逐项取消。点击“加入搜索词”后，用空格追加至已有输入，不覆盖用户输入；不自动提交。

纯图片、草图、音视频和区域不自动生成语义关键词。可选用已有标题、说明或转写片段；无可用文字时提示“此内容没有可直接使用的文字，可手动输入关键词，或切换 Agent 模式添加参考”。

若未来接入图搜或 OCR，应作为用户明确调用的能力单独展示；本版本不默认所有平台都支持。复制的文字随输入可编辑，原卡片修改不自动改写已形成的搜索词。

## 不隐藏按钮的理由

个人模式仍需要将刚读到的概念快速带入搜索。固定按钮位置便于学习；通过“提取文字到搜索框”的说明限制预期。它不承担复杂理解，因此不会让用户误以为单个平台能理解整张画布。


# 三 Agent 模式的搜索流程

## 选择范围并执行

聚焦输入框后显示常用来源及多选标记。点击平台只选中或取消，不打开平台页面，也不立即开始检索。选择本机及两个平台时，仅在三项范围内搜索；参考卡原来的平台不会自动加入检索范围。

未选来源时显示“本机＋全网”。本机使用当前已开放的文件或索引范围，界面可展开查看；全网指可访问的网络内容，不承诺覆盖所有页面、账号内内容或设备。

用户输入目标，可附加参考。点击“开始搜索”后，任务记录此次问题、参考范围与检索来源。面板显示简短任务理解和当前进度，避免展示不可核对的内部推理。

## 仅添加参考但没有问题

参考不等于搜索意图。输入为空时不直接启动。显示可点击建议，例如“找相似案例”“寻找不同做法”“补充相关研究”；点击建议将其写入输入框，允许编辑，再明确提交。

## 画布参考的处理

支持资源卡、想法卡和设计对象卡；支持整卡、片段与区域。默认使用已选片段或卡面已保存内容。将区域加入时，先显示包含的卡片清单，可排除不相关项；搜索使用提交时的卡片集合，后续移动卡片不改变进行中的任务。

设计对象卡默认提供现有预览、文字说明和已关联材料。进入原应用读取更多对象内容属于另一个明确动作，不因附加卡片就假定能够读取整个设计工程。

标签显示标题、来源类型及范围，如“访谈摘录 12:30 至 13:05”。同一片段重复添加时合并提示；同一文件不同片段允许分别保留。可展开预览、移除标签、定位回画布。

## 本机参考与网络检索

默认向外部检索服务提交为搜索所需的查询词，不直接上传完整本机文件或整段私人记录。界面提供“查看检索词”；若某能力确需上传图片或文件，应使用独立的明确操作。搜索参考本身与平台收到的查询内容分开呈现。

## 执行中与结果

任务面板显示来源级进度，如“本机已完成，平台 A 搜索中，平台 B 暂不可用”。提供停止；已得到的结果保留。开始后修改问题或范围只改变草稿，不静默改变当前任务；再次提交创建新的搜索批次，避免新旧结果混淆。


# 四 模式切换与草稿恢复

## 各自保存 两种草稿

个人模式保存搜索词、单个平台、平台浮层状态与页面位置；Agent 模式保存问题、参考集合、多选来源与任务结果。收起面板或切换模式都不删除草稿。

首次切入尚无草稿的另一模式，只复制当前输入文字，不自动提交。目的模式已有草稿时恢复原草稿，并提供“带入当前搜索词”入口，由用户决定是否替换。

| 切换情况 | 处理规则 |
| --- | --- |
| 个人转 Agent | 首次复制关键词；单个平台可作为首次范围。后续恢复 Agent 原草稿，不覆盖。 |
| Agent 转个人 | 首次只复制问题文字，提示可改成关键词；恢复个人单选平台，首次无平台时要求选择。 |
| Agent 有多份参考 | 切换个人时保存在 Agent 草稿中；不自动拼接进关键词。个人可重新调用取用按钮。 |
| Agent 选了多个来源 | 不静默挑选第一个作为个人平台；使用个人已有选择或提示单选。 |
| 画布取用过程中切换 | 先退出未确认的取用，保留已有输入；未确认选择不迁移。 |
| Agent 正在检索时切换 | 任务在后台继续，顶部显示任务状态入口；切换不等于停止。 |
| 切回上一模式 | 恢复该模式最近的输入、范围、参考及结果，按需展开原面板。 |

## 首次默认与记忆

首次默认个人模式，使直接搜索入口容易理解；之后记住用户上次模式。个人平台选择可记忆，但必须始终显示平台名称。当前项目的参考集合不跨项目自动带入；新项目有独立草稿。

## 与个人和共创工作状态的关系

用户可以在自主探索状态调用一次 Agent 搜索，也可以在共创状态手动使用某个平台。顶部模式只决定这次检索由谁执行，不切换全局共创状态，不改变 Agent 的主动建议设置。


# 五 结果预览与加入画布

## 个人结果

用户在平台浮层中自主浏览。若支持内容选取，点击“加入画布”后可选择整页或当前片段，并预览标题和出处；不支持时提供“在外部打开”，继续使用外部圈选收集入口。不要提供看似成功但无法执行的摘取按钮。

## Agent 结果

结果以可核对的来源条目为主体，按来源或主题分组。每项显示标题、来源、摘要或片段、可用时间信息、网页或文件标记，以及打开、预览、加入操作。本机命中显示可辨认的文件名与位置；不要伪装成网页。

Agent 可另附“与参考的关联说明”，明确标注为 Agent 解读，和原始材料片段分开。汇总不能替代结果出处；只有一个来源时也不表现成多源共识。

## 搜索结果与卡片的分界

搜索命中先停留在结果面板。用户点击“加入画布”或拖入画布时，才创建资源卡；可多选批量加入。将 Agent 的综合判断保存到画布时，另建想法卡，并连接其引用的来源。

通过按钮加入时，提供“当前视野”与“指定区域”两个位置选项；拖拽时按落点放置。批量加入在用户指定位置形成一组，不重新排列已有内容。

成功后反馈“已加入 3 张资源卡”，提供定位入口。重复 URL、文件身份或片段已存在时提示“画布中已有”，提供定位；如需另一个视图，由用户明确选择，不覆盖已有批注。

## 退出与继续

关闭平台或任务面板后，恢复原来的画布视野与焦点。已加入卡片保留；未加入结果可从本次搜索记录重新打开。搜索记录保存模式、查询、范围与时间，不假定外部网页始终可以重新访问。

## 示例

个人路径：选中想法卡中的“操作可撤回” → 加入搜索词 → 编辑为“点餐 撤回 交互” → 点击一个案例平台 → 浏览并收集截图。

Agent 路径：添加访谈片段与当前设计预览 → 输入“寻找让老年人理解撤回操作的案例” → 选两个案例平台 → 查看带出处结果 → 将有用资源加入区域 → 按需保存比较结论为想法卡。


# 六 状态与异常反馈

| 状态或问题 | 界面表现与恢复 |
| --- | --- |
| 输入为空 | 执行按钮不可用；个人点击平台可打开搜索入口；Agent 参考不代替明确问题。 |
| 未选个人平台 | 保留搜索词，展开来源面板，提示“选择一个平台后搜索”。 |
| 平台无法嵌入 | 提示“此平台需在外部打开”，保留查询并提供打开入口。 |
| 登录失效 | 个人显示平台登录入口；Agent 标明该来源待登录，其他来源继续，不暗中扩大范围。 |
| 来源不支持 Agent 检索 | 在 Agent 模式标记不可选并说明，可转为个人打开；不保证所有平台两种模式都可用。 |
| 本机范围不可用 | 明确显示本机未执行；网络范围仍按原计划执行。提供调整本机范围或重试入口。 |
| 部分来源失败 | 保留成功结果，显示失败来源与重试；不自动转全网补搜。 |
| 全部无结果 | 说明本次范围，建议调整关键词、减少限制或扩大范围；扩大由用户操作。 |
| 参考失联或解析失败 | 指出具体参考。可移除或重选；任务中跳过时显式记录，不表现为已使用。 |
| 重复提交 | 启动反馈立即可见，同一提交不创建重复任务；新的明确提交生成新批次。 |
| 停止或关闭 | 停止结束当前任务并保留结果；关闭只收起面板。 |
| 网络中断 | 保留输入、参考与已得到结果，恢复后可重试失败部分。 |

## 键盘与可访问性

Tab 按布局顺序访问取用按钮、输入框、执行按钮与模式菜单；选中模式或平台后状态可被读出。Enter 提交搜索，但中文输入法正在组词时不触发。来源选择同时用文字和选中标记表达，不只靠颜色。

打开菜单与浮层后焦点进入对应内容；关闭后回到触发入口。参考移除按钮可用键盘操作。加载、加入成功、失败等状态通过简短提示同步呈现，不强制抢走当前输入焦点。


# 七 原型页面与验收清单

## 需要绘制的关键状态

| 编号 | 页面状态 | 需表达的区别 |
| --- | --- | --- |
| 01 | 个人模式空态与常用平台面板 | 单选说明；未选平台；取用按钮的用途 |
| 02 | 个人从画布提取文字 | 画布取用状态；预览确认；可编辑关键词 |
| 03 | 个人平台浮层 | 有词直接搜索；无词打开入口；退出与外部打开 |
| 04 | Agent 输入与多来源选择 | 参考标签；多选；清空后默认本机与全网 |
| 05 | Agent 参考预览 | 卡片范围、区域成员、移除与回到原处 |
| 06 | Agent 搜索进行中与结果 | 来源级进度、停止、部分失败、来源与解读分离 |
| 07 | 模式切换与草稿恢复 | 两套草稿；参考保留；多选不变成隐式单选 |
| 08 | 结果加入与回到画布 | 资源卡与想法卡区分；加入位置；重复内容反馈 |

## 验收任务

A 个人模式取用一段文字后，原输入仍在，新增文字可编辑，未点击提交前不开始搜索。选纯图片不会被误认为平台已理解图片。

B 个人选择平台时，含关键词立即搜索；没有关键词只打开入口。更换平台不留下多份叠加浮层，来源面板始终表达单选。

C Agent 选择两个来源时只查两者；清空后可见地恢复本机与全网。参考来自平台 A，不会导致检索范围自动加入 A。

D Agent 仅有参考、没有目标时不自动检索；选择建议可填入输入，再提交。引用区域的实际内容范围可检查。

E Agent 转个人再切回，问题、参考和来源完整恢复。后台任务有入口；修改输入不静默改变进行中的搜索。

F 某来源失败时保留其他结果并说明缺失。结果加入画布之前不生成持久卡片；加入后可回到来源，并能识别重复材料。

## 原型验证重点

观察用户能否区分“搜索参考”与“搜索范围”，能否预判个人点击平台会立即打开、Agent 点击只多选，以及能否理解左侧按钮在两种模式中的用途。如果仍频繁误用，优先调整按钮文案与取用预览，再评估是否将个人取用收进输入框菜单。
